Generative AI for Science

Author: J. Paul Liu
Affiliation: North Carolina State University
Year: 2026

Abstract

This book presents a hands-on introduction to generative AI methods for scientific applications, including physics-informed neural networks (PINNs), diffusion models, and graph neural networks. It covers applications in climate science, biology, and materials science, with all concepts paired with executable Python code and Google Colab notebooks.

Keywords: Generative AI, Machine Learning, PINNs, Scientific Computing, Deep Learning, Climate Modeling
